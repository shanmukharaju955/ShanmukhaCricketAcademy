## 🌟 Academy Highlights & Features

- **Multi-Page Architecture & Dynamic Navigation**:
  - `#/` - **Home**: Interactive 3D Leather Cricket Ball Showcase, Quick Tour & Academy Snapshot.
  - `#/programs` - **Training Programs & Fees**: Grassroots, High Performance, Weekend Warrior, and Interactive Fee Calculator.
  - `#/ai-hub` - **AI Biomechanics & Video Analyzer**: Real-time Bat Speed, Elbow Angle (15° ICC rule), Bowling Release Velocity, and Stance Telemetry.
  - `#/pitch` - **Hawk-Eye 3D Pitch Visualizer**: Good Length, Yorker, Bouncer pitch map visualizer with dynamic speed controls.
  - `#/matches` - **Live Match Center & Drills**: Live scoreboards, match commentary, and coach-recommended homework drills.
  - `#/store` - **Pro Gear & Kit Store**: English willow bats, protective gear, and instant WhatsApp Checkout.
  - `#/about` - **Elite Coaches & Facility**: Coach Shanmukha BCCI Level 3 credentials, turf pitch details, and gallery.
  - `#/contact` - **Admissions & Booking**: Direct hotline links, WhatsApp consultation, and net slot booking.

- **Unified Portal (Student & Admin Login)**:
  - **Cadet Student Portal**:
    - Digital Player ID Card with printable modal
    - Telemetry tracking (bat speed, accuracy, consistency)
    - Tuition Fee Receipt with printable official receipt
    - Training schedule and homework drill checklist
  - **Admin Control Room (Password Protected)**:
    - Coach profile management (add, edit, toggle visibility)
    - Programs & fee structure updates
    - Student records & enrollment management
    - Turf net reservation monitor & store order desk
    - *All modifications are restricted exclusively to the Admin Portal.*

## 🚀 Quick Start Guide

### 1. One-Click Launch (Windows)
Double-click `Open_Website.bat` to automatically start the local server and launch your browser at `http://localhost:3000`.

### 2. Manual Command Line
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
